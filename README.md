# Better Item Identification

The aim of this plugin is to improve upon the built-in Item Identification plugin by adding expanded labeling options.

Better Item Identification adds small identifying text labels over items with similar-looking sprites.

It labels items from categories such as seeds, herbs, saplings, logs, ores, bars, gems, potions, jewellery, tablets, scrolls, wines, unfinished potions and other visually similar items.

## Features

- This version separates unfinished potions from finished potions, so you can label them separately
- Labels supported items in your inventory and bank
- Supports short and medium label modes
- Lets you choose the overlay text color
- Lets you enable or disable item categories individually

## Usage

Enable the plugin from RuneLite's plugin list, then open the plugin settings to choose which item categories should show labels.
